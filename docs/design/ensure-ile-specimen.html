设函数 g(x) = x³ − 2（x ∈ R），

f(x) ={ g(x) + x + 4，x < g(x)； { g(x) − x，x ≥ g(x)。

求 f(x) 的值域。

你上次停在　「试了 x = 1 是 −2、x = 2 是 4，所以根在 1 和 2 之间。」

下一步　先把这个根夹到两位小数，再回头看 g(x) − x 那一支。

二、逐小步 答案优化，一轮只比一步

两种笔迹并排站着。选「合」才出现方格演算区——那是他自己写的。

第 2 步

「x < g(x) 就是 x³ − x − 2 > 0，也就是 x > 1.52 左右。」

这一步对　把 x < g(x) 化成 x³ − x − 2 > 0，思路对。差在最后一句——「1.52 左右」还是猜的。教师版：先证明 φ(x) = x³ − x − 2 在 R 上单调增，只有一个根；再用 φ(1.5) = −0.125、φ(1.6) = 0.696 把它夹住。

在这里用自己的话把这一步重写一遍。写不完整就写你卡住的那半句。
