en∫ure — 品牌字标三版

把 ensure 的 s 换成 LaTeX 积分号 ∫（U+222B，字标里是重画的路径，不是字体字符）。∫ 同时有升部和降部，三版都各自处理了「撑高整行、重心上移」，处理方式不同，见每节说明。

所有图形都是内联 SVG 路径（不依赖本机字体），16px 档按真实像素显示，可以把页面缩放到 100% 直接看它在小尺寸下的样子。

一 · 三版字标 × 三档尺寸

大字（96px 高）看造型与 ∫ 的钩；中档（40px）看文件标题栏/安装器里的实际观感；16px 是极限档。

深底用的是同一份路径、只换墨色（#17191B → #EDEFF2），位置不动。

二 · -ILE 的四种处理

ILE = In Learning Environment。李只定了 en∫ure，后缀按四种方式处理，越往下越弱：小体大写并入字标 → 竖线分隔 → 只用颜色/字重区分 → 完全不带。

16px 档：小体大写的 ILE 已经在 x-height 的 72%，三根竖笔画在 16px 高时并成一条深色带——所以小尺寸下只出 en∫ure，ILE 交给产品名文字。

三 · 方形 mark（应用图标）

∫ 单独成形、不做字标缩放（小尺寸下缩字标必糊）。1024 圆角底 rx230 + 品牌蓝 #4D6BFE + 白 ∫。

geometric-cjk 是「∫ + 因需」的对照版：16px 时两个字已经糊成两条横带（下面那两行 ::），只适合 ≥64px 的场合（关于页、启动画面），不能当应用图标主版。

四 · 托盘图标（16 / 32 单色）

托盘是单色剪影：Template 版走系统黑（macOS 会自动反色），blue 版固定 #4D6BFE（generate-tray-icons.mjs 的要求）。下面只展示 32 与 16 两档真实像素。

16px 档三版都还在：∫ 不是一根竖线，而是一条带钩的斜杆（钩各占 1px）。serif 版在 16px 下钩太粗（笔画 4px），会和 ∫ 的竖杆并成一坨，所以托盘主版选 geometric。
