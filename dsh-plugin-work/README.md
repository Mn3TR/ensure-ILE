# dsh-plugin-work

ensure-ILE 的 **work 模式（显示「独立做题」）**：学生自己做，交上来，我们判。

三个模式里只有它先要结果：guide 从零带，work 先放手，HRL 拿结果去打磨。

## 它做什么

1. 把系统提示换成「独立做题」（commons 的 common + bank + `prompts/work.md`）
2. 注册 `read_note`——**给模型判卷用，不给学生看**（备注里写着「怎么验对不对」，那是判卷标准）

## 判两件事

1. **结果对不对** —— 代回原题 / 回原文找依据
2. **说清没有** —— 每一步为什么这么做

两件都过才算过。结果对、说不清 → `work.attempts` 记 `partial`、`status` 回 `guide`，写 `handoff` 让学生去引导模式补「为什么」。他不一定做出来了，只是不知道自己怎么出来的。

## 重交只给一次

第一次不对：只指出错在哪一步（不给方法），让他重交。
第二次还不对：转引导。

理由：work 的价值在「自己先撞一次」，一次就转，work 就退化成 guide 的序章了。

## 状态怎么走

work 没有自己的状态，题目在判之前是 `new`：

- 判过 → `review`
- 判不过 / 讲不清 → `guide`

## 边界

- 不给提示、不给答案、不替他总结
- 查资料允许（考的是解题，不是背书）
- 用笨办法、写得丑、跳步，都不是判错理由

## 和别的模式

| | guide | work | HRL |
|---|---|---|---|
| 起点 | 还没做出来 | 拿到题自己做 | 已有答案 |
| 我们做什么 | 给注意力不给动作 | 不插手，判结果和说理 | 评价、对比、改 |
| 结束 | 他自己走完 | 判过，或转 guide | 改到站得住 |
