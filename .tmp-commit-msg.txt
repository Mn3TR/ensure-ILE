fix 5。另附四个同步场景的操作步骤、失败信号表（静默不生效的几种长相）与同步后
固定事项清单。

二、scripts/verify-patch-references.mjs
补上一道缺的检查：resolutions 里写了 patch: 不代表补丁生效，判据是 yarn.lock 里
有没有 @patch: 条目。当前实测 29 份补丁 28 有效，1 份无施主

图里，补丁本身是活的，留着等它回来）。pi-ai 那份是 2026-10-28 修好的现成案例。
脚本故意还没接进 check:layout：接进去会把「vendor 里留着一个没人装的包」这种合法
状态也判成失败。

三、字标 en∫ure 设计稿（docs/design/brand/）
把 ensure 的 s 换成 LaTeX 积分号 ∫。三版：serif（从仓库自带的 ILE Song 取轮廓，
和「视觉层＝演算纸」同一套语言，推荐主选）、geometric（手绘，现代产品名备选）、
mono（小尺寸）。generate.py 出轮廓、render.mjs 用 sharp 出 PNG、preview.html 离线
可看。第一版 geometric 与 mono 的 x-height 不齐（n 顶端高 16px、u 底端低于基线
16px），根因是手绘把拱顶/碗底中线当成了墨迹边，已修；实测 e/n/u/r 与 ∫ 的比例
落在 1.34–1.48×。16px 托盘只有 serif 与 mono 可用，geometric 的上钩只剩 2px。
只出稿不落地：build/ 下的图标仍是 DeepSeek 鲸鱼，macOS 的 app-icon.icon 与 icns
必须靠 macOS 的 ictool 导出，Windows 上改会让 icons:check 直接红。

四、单会话内改上下文的可行性研究（docs/research/）
只研究不动手。结论：改历史 = append 一条带 surfaceOp 的事件（surface 投影，
messages 的唯一来源是 session.deriveMessages），节点 0 是 system prompt 只能被一条
只盖住它自己的 system/message 重写；没有 truncate/rewind；替换副本是 model-only，
学生屏幕上的历史不会变。四条路径里「开新会话 + 摘要当第一句」是主路径
（bankmanager 的三段式已经能做），「插件调 ctx.compaction.compactRegion」是兜底，
改 harness 加 resetHistory 每次升 pin 都要重打，不建议。
顺手查到一个现存缺口：四个预设都没装压缩引擎（compaction-basic / command-compact
被 web-app 在 host 平面 disabled，真实例在 standard 预设的隔离组里），所以没有
/compact 也没有自动压缩，长会话撞窗口会硬失败——已记进 AGENTS 的「还没做」。
